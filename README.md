# Endothelin receptor composition of human cardiac sympathetic ganglia

Code and processed data for the EDNRB and EDNRA measurements in human sympathetic
ganglion, heart and coronary artery.

## Running

```
pip install numpy pandas scipy

python analysis/00_rank_universe.py        --proj .
python analysis/01_receptor_ratio.py       --proj .
python analysis/02_gene_set_analysis.py    --proj . \
    --lengths data/transcript_lengths_refseq_select.csv --nperm 5000
python analysis/03_composition_control.py  --proj . \
    --lengths data/transcript_lengths_refseq_select.csv \
    --scdata <directory containing GSM7728058_*>
python analysis/04_percentile_null.py      --proj . \
    --lengths data/transcript_lengths_refseq_select.csv \
    --scdata <directory containing GSM7728058_*>
python analysis/05_marker_modules.py       --proj .
python analysis/06_excluded_fragment.py    --proj .
python analysis/07_ganglion_celltypes.py   --indir <directory containing GSM7728058_*.gz> \
    --outdir results
python analysis/08_coronary_celltypes.py   --files <tabula.h5ad> <plaque.h5ad> \
    --outdir results
python analysis/09_heart_celltypes.py      --outdir results
python analysis/10_celltype_table.py       --proj .
python analysis/11_celltype_merge.py       --proj .
python analysis/12_supplementary_table3.py --proj .
```

`02` and `03` use permutation nulls, so P values are sampling estimates. `02` corrects over
30 sets by default; pass `--family-size` to change the denominator.

## Scripts

| script | produces | figure or table |
|---|---|---|
| `00_rank_universe.py` | within-library percentile ranks on a fixed gene universe | — |
| `01_receptor_ratio.py` | EDNRB:EDNRA within each of the nine libraries | 1E |
| `02_gene_set_analysis.py` | twenty gene sets against abundance- and length-matched controls | 1D |
| `03_composition_control.py` | each receptor's rank among 300 composition-matched genes | 1F |
| `04_percentile_null.py` | the empirical null percentile for that matching | 1F |
| `05_marker_modules.py` | marker module scores in the three retained fragments | 1C |
| `06_excluded_fragment.py` | marker content of the excluded fragment 2b | Supplementary Table 1 |
| `07_ganglion_celltypes.py` | receptor detection per sympathetic ganglion cell class | 1H |
| `08_coronary_celltypes.py` | receptor detection per coronary artery cell type | 1H |
| `09_heart_celltypes.py` | receptor detection per cardiac cell type | 1H |
| `10_celltype_table.py` | the four cohorts pooled onto common columns | 1H |
| `11_celltype_merge.py` | canonical cell-type merge, Fisher test, detection-floor sensitivity | 1H |
| `12_supplementary_table3.py` | per-dataset receptor values and fold spread | Supplementary Table 3 |

Panels 1A, 1B and 1G are images and are not generated by code.

## Data

| file | what it is |
|---|---|
| `data/counts_all_fragments.csv` | patient gene counts, all four ganglion fragments |
| `data/counts_qc_pass.csv` | the three retained fragments only |
| `data/vst_normalized.csv` | the retained libraries, variance-stabilised |
| `data/metadata.csv` | fragment identifiers and the exclusion record |
| `data/ziegler_tpm_matrix.csv` | six reference donor libraries, TPM, requantified from ENA PRJNA967653 |
| `data/transcript_lengths_refseq_select.csv` | RefSeq Select transcript length per gene symbol |

`results/receptor_by_celltype_ganglion.csv` and `results/receptor_by_celltype_atlases.csv`
are the per-cell-type tables read by `11` and `12`.

Not redistributed here, downloaded from source:

- GEO **GSE241386**, single-nucleus sympathetic ganglion, for `03`, `04` and `07`.
- HeartMap (Broad Single Cell Portal **SCP3689**), Tabula Sapiens Vasculature and the Plaque
  Atlas (CZ CELLxGENE), for `08` and `09`.

Raw sequencing reads are deposited in GEO under accession [accession].

`data/metadata.csv` records the year of collection only.
